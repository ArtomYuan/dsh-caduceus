本刀未改 `docs/DESIGN.md`、未安装/未重启、未触碰生产 `~/.dsh` 数据。

## 1. 改动

### 1.1 终稿带标题

- `src/bridge/bridge.ts#sendFinal`：发送终稿前读取当前标题（缓存 `state.title` → `sessionTitle.get(session)`）；标题非空时正文为：
  ```
  ▸ {标题}

  {正文}
  ```
  标题为空/未就绪时**不加首行**，也不写「未命名」。
- 终稿仍是**新发消息**（reply / sendText），不编辑过程卡；若本轮 provider 标题在终稿之后才落盘，**不补发、不编辑终稿**，下一轮自然带标题（按需求）。
- 150 KB 终稿上限按「标题行 + 正文」整体计算，不会因加标题超限。

### 1.2 `/sessions` 列表

- 每行格式：`▸ {标题} · {相对时间} · {sessionId 前 8 位}`；**当前会话行首加 `* `**。
- 标题取缓存 / `sessionTitle.get(session)`；空标题显示 `（未命名）`（不再是空白）。
- 相对时间：`刚刚` / `N 分钟前` / `N 小时前` / `N 天前`；本进程没有该会话时间戳时显示 `—`（典型：上一会话）。
- 排序：当前会话在前，上一会话（`/new` 或 `/resume` 切换前）在后。
- 末尾固定提示：`用 /rename <标题> 改当前会话名`。
- 只列**本 scopeKey**（当前聊天/话题）的会话：桥接层只持有该 scope 绑定的会话，跨话题 session 不会出现。

### 1.3 状态卡抬头（确认上一轮修复）

- 复核 `#afterAgentReady`：`create`/`resume` 返回后从 `sessionTitle.get(session)` 拉标题，并就地 patch 已有状态卡（同一 message_id，不新发）。
- 卡内首行保持 `会话：{标题}`；标题未就绪仍是「标题生成中」。
- 本刀补了显式断言：agent 就绪重渲后状态卡第一行 `text.content === '会话：服务端标题'`。
